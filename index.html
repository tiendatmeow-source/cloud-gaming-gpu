FAQ

Game AAA chơi mượt không? 🎮

Đây là cloud desktop qua noVNC (truyền ảnh qua HTTP) nên phù hợp game nhẹ, game cũ, emulator, game 2D — không phải streaming độ trễ thấp kiểu Moonlight. Giảm resolution desktop xuống 1280×720 sẽ mượt hơn nhiều. GPU VM tốt nhất dùng cho AI/compute; desktop render bằng LLVMpipe.

URL tunnel đổi mỗi lần chạy? ☁️

Đúng — trycloudflare tạo URL ngẫu nhiên mỗi phiên. Mỗi lần chạy lại notebook là URL mới; copy lại từ output Bước 2 hoặc tab Tổng quan của dashboard cũ.

Treo bot có an toàn không? 🤖

Token bot nằm trong file .env tách riêng script, log không in token. Nhưng notebook bị ngắt khi phiên hết hạn → bot chết theo. Phù hợp bot "thử nghiệm"/cá nhân, không phải production 24/7 thật sự.

Chạy cái này có bị cấm tài khoản? ⚠️

Có rủi ro. Chạy game, remote desktop và workload nền dài hạn vi phạm ToS của Google Colab và Kaggle. Đây là dự án giáo dục/thử nghiệm — dùng cân nhắc, tự chịu rủi ro, đừng lạm dụng tài nguyên.

Chạy được trên máy riêng? 💻

Được — pip install aiohttp rồi python dashboard.py là có dashboard ở localhost:8080. Cloud desktop cần Xvfb + x11vnc + noVNC (apt install).

Sẵn sàng biến notebook thành cloud GPU server?

Không cài đặt. Không thẻ tín dụng. Chỉ 2 ô code.
